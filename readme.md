# To-Do List Application

## Overview

This is a simple JavaScript-based To-Do List application that allows users to:

* Add new tasks.
* View the task list.
* Mark tasks as completed.
* Automatically remove completed tasks.
* Show and hide the task list panel.

## Features

### Add Tasks

Users can enter a task in the input field and click the add button to create a new task.

### Input Validation

The application prevents empty tasks from being added. If the input field is blank, an alert message is displayed.

### Complete Tasks

Each task includes a checkbox. When checked:

* The task text is displayed with a strikethrough effect.
* The task is automatically removed after 500 milliseconds.

### Show Task List

The task list container can be displayed with a customized background color.

### Hide Task List

The task list can be closed using the close button.




## Technologies Used

* HTML5
* CSS3
* JavaScript
